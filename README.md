# 世界信息汇

自动汇集公开 RSS 的标题、原发布时间、来源及原文链接。固定规则分类、URL 去重、变更记录；不调用生成模型，不收集全文或图片，不需要个人 API Key。

## 内容与来源

13 个分类覆盖科技、数码、交通、旅游、本地生活、食品、家居、教育、就业、文化、健康、财经和体育。首批订阅源来自 IT之家、少数派和中国新闻网公开 RSS。分类按标题关键词匹配，仅作为导航，不表示内容经过事实核验。来源许可需要持续关注；公开 RSS 并不意味着全文转载许可。

来源登记在 `config/sources.json`；只抓取白名单 HTTPS 域名，检查 robots，限制响应大小、超时、DNS 地址和 XML 类型。不跟随重定向，不绕过访问限制。36氪订阅接口在初次验证中返回 HTML，因此没有收录。

## 自动运行

GitHub Actions 每小时第 7 和 37 分钟计划抓取，并发布到 GitHub Pages。平台可能延迟调度。自动提交保存来源状态和真实元数据；失败来源保留历史数据。全部失败时停止新部署，线上保留上次成功版本。运行失败在仓库 Actions 可见。

运行使用平台管理的 GITHUB_TOKEN，无模型密钥、付费数据库或本地常驻进程。仓库和标题数据公开。静态首页、分类、条目页及历史可供抓取；JSON Feed、RSS、Atom、JSON API 和 sitemap 同时生成。搜索收录与 AI 引用不作保证。

## 本地运行

Node.js 24：`npm ci`、`npm test`、`npm run collect`、`npm run build`。生成文件在 dist。`SITE_URL` 可以覆盖正式地址。网络必须将来源域名解析为公共 IPv4；使用保留地址映射的代理环境会被安全检查拒绝。

## 更正与来源退出

可提交 Issues。禁用来源修改 enabled；永久排除指定原文 URL 加入 `config/removed-urls.json`，之后重新运行工作流。过去提交中的元数据仍可能存在于 Git 历史，涉及隐私时需单独清理历史。保留期限为首次发现后 90 天，最多 10000 条记录；单条最多 10 个历史版本。
